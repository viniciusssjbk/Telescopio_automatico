# 🔭 Telescope Tracker - Sistema de Controle e Rastreamento Astronômico

## Sobre o Projeto

O **Telescope Tracker** é um software desenvolvido em **C++ utilizando SFML** com o objetivo de criar uma interface de controle e visualização para um telescópio automatizado.

O sistema recebe dados astronômicos de objetos celestes, calcula suas posições no céu através de coordenadas de observação e apresenta uma interface gráfica moderna para acompanhamento do movimento do telescópio.

O projeto busca integrar:

* Software de controle
* Dados astronômicos reais
* Simulação de movimentação
* Controle de motores
* Interface gráfica de monitoramento

---

# 🎯 Objetivo

Criar uma plataforma capaz de controlar e acompanhar um telescópio automatizado, permitindo:

* Selecionar objetos celestes
* Obter coordenadas astronômicas
* Calcular posição aparente no céu
* Simular movimentação dos motores
* Futuramente controlar hardware real através de Arduino
